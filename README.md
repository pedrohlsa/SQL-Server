# SQL-Server

Repositório criado para guardar os scripts de Banco de Dados que estou desenvolvendo.

Sobre os projetos:

database_academia.sql:
Criei um sistema para gerenciar alunos e a manutenção dos aparelhos.
Tabelas relacionadas, chaves primárias automáticas (`IDENTITY`) e regras de segurança (como a idade mínima de 14 anos usando `CHECK`).

database_biblioteca.sql:
Um modelo para organizar livros e autores.
Chaves estrangeiras (`FK`) para ligar as tabelas e garantir que nenhum dado fique solto ou errado.
